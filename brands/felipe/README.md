# Brand Kit — Felipe Bravo

Este diretório contém as regras usadas pelo Carousel Studio para a marca pessoal de Felipe Bravo.

## Estrutura esperada

```
brands/felipe/
├── brand.json
├── rules.md
├── agent-instructions.md
├── layouts.json
├── photo-library.json
├── photos/
│   ├── dark-authority/
│   ├── dark-accessible/
│   ├── light-consultive/
│   └── full-body/
└── references/
```

As pastas `photos/` e `references/` receberão os arquivos visuais originais. O sistema deve sempre usar os arquivos reais; nunca recriar fotos ou identidade visual.
