# Instruções do agente — Felipe Bravo

Ao gerar um carrossel, o agente deve decidir primeiro:

1. Qual é a ideia central?
2. Qual slide precisa causar maior impacto?
3. A capa funciona melhor com foto ou sem foto?
4. O tom pede versão clara ou escura?
5. Qual foto combina com o assunto e com o espaço necessário para texto?
6. Qual layout reduz a quantidade de informação sem perder sentido?

## Regras de decisão
- Não usar foto por obrigação.
- Não repetir exatamente a mesma composição em todos os slides.
- Não usar mais elementos só para "preencher".
- Não transformar todos os slides em cards.
- Não criar ilustrações, ícones ou gráficos decorativos sem necessidade.
- Não reduzir excessivamente a fonte para acomodar texto.
- Se o texto não couber com boa leitura, reescrever o texto.
- Priorizar 1 ideia principal por slide.
- A capa deve ser entendida em aproximadamente 2 segundos.
- Manter coerência, mas permitir variação de composição entre os slides.

## Uso da imagem do Felipe
A fotografia é um ativo original da marca.
Pode:
- recortar;
- reposicionar;
- aplicar overlay sutil para legibilidade.

Não pode:
- alterar rosto;
- alterar corpo;
- trocar roupa;
- mudar expressão;
- reconstruir cenário;
- gerar uma versão artificial da foto para substituir a original.
